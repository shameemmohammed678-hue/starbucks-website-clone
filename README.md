Starbucks Website Clone ☕️

A multi-page Starbucks website clone built from scratch using HTML, CSS, and JavaScript. The project recreates the design, layout, and user interface of most of the main Starbucks website pages as a frontend development practice project.

🚀 Features
Starbucks-inspired homepage
Responsive header and navigation
Promotional sections
Menu page
Store locator page
Gift Cards page
Rewards page
Login / Sign-up pages
Interactive JavaScript functionality
Interactive buttons and UI elements
Responsive layouts for mobile devices
CSS Grid and Flexbox layouts
Hover effects and styled components
Responsive forms and images
Embedded map using iframe
🛠️ Technologies Used
HTML5 – Website structure
CSS3 – Styling and responsive design
JavaScript – Interactive functionality and dynamic UI behavior
CSS Grid & Flexbox – Page layouts
CSS Media Queries – Mobile responsiveness
📱 Responsive Design

The website is designed to work across different screen sizes, including desktop, tablet, and mobile devices.

Mobile responsiveness includes:

Single-column layouts
Responsive navigation
Responsive images
Mobile-friendly forms
Stacked content sections
Responsive buttons
Mobile-friendly menu layout
Responsive Gift Cards and Rewards sections
Mobile-friendly store locator
Prevention of horizontal scrolling
🎯 Project Purpose

This project was created to improve my frontend web development skills by recreating a real-world website with multiple pages and interactive elements.

Through this project, I practiced:

Building multi-page websites
HTML page structuring
CSS styling
CSS Grid and Flexbox
Responsive web design
JavaScript DOM manipulation
Creating interactive UI components
Form design and validation
Navigation design
Working with images and external resources
